# 디오엠(DOM) 사이트

## 로컬에서 보기

```bash
python3 -m http.server 4173
```

- 회사 홈(다른 사람이 검색할 공개 페이지): http://localhost:4173
- 운영 포털(로그인): http://localhost:4173/portal.html

## 인터넷에 올려 다른 사람이 보게 하려면

회사 소개 페이지(`index.html`)를 GitHub Pages에 올리면 `https://아이디.github.io/저장소이름/` 주소가 생깁니다. **운영 포털과 가공 프로그램은 사내(또는 이 맥북)에서만** 열리도록 막아 두었습니다. 입고·가공 기록은 브라우저에만 있어서, 인터넷에 올려도 다른 컴퓨터와 자동으로 공유되지는 않습니다.

1. [GitHub](https://github.com)에서 공개(Public) 저장소를 만들고 이 폴더를 올립니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 둡니다. `main`에 푸시하면 자동 배포됩니다.
3. 생긴 `https://...` 주소로 회사 홈이 열립니다.
4. [네이버 서치어드바이저](https://searchadvisor.naver.com/)에서 그 주소를 등록하고 사이트맵(`sitemap.xml`)을 제출합니다.
5. 검색어 ‘디오엠’ 반영까지는 며칠~수 주 걸릴 수 있습니다. 올렸다고 바로 네이버 1페이지에 뜨지는 않습니다.

## 컴퓨터에 앱으로 설치

Chrome 또는 Edge로 사이트를 연 뒤 **앱 설치**를 누르면 창만 있는 앱처럼 실행됩니다. 회사 홈의 ‘컴퓨터에 앱 설치’ 버튼을 써도 됩니다.
